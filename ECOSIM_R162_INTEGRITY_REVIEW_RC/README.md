**Elsődleges dokumentáció:** [README_R162.md](README_R162.md). A korábbi R161 forráskódját és bizonyítékait megőriztük. Az **új, aktív** kiadási parancs: `./verify_release_r162.sh`, nem a történeti R161 ellenőrző.

`PASS_OFFLINE_ONLY` · `GAMEPLAY_STOP` · aktuális `market/team` adatok hiányoznak.
