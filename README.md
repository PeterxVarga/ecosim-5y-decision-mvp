# EcoSim offline research code

This repository retains historical offline research, source-integrity checks and tests. It is not a live game automation service, and its historical sample results are not validated predictions.

**Game actions are disabled.** Do not upload authentication credentials, private team information, live game state, or non-public decision evidence.

The repository is currently public. Removing guidance from the latest branch does not remove already published Git history, other branches, or forks.
